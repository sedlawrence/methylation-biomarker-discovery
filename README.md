# DNA Methylation Analysis Workflows

This repository contains two computational analyses using DNA methylation data in the context of Alzheimer's disease:

1. **Longitudinal progression modelling** — compares machine learning approaches for predicting transitions between control, mild cognitive impairment (MCI), and Alzheimer's disease (AD) from longitudinal methylation profiles.
2. **Whole-blood differential methylation** — processes GEO series GSE59685 and tests for differentially methylated positions between case and control groups in whole-blood samples.

The analyses use different cohorts, input formats, and software environments. Their scripts and outputs are maintained separately.

## Repository map

| Path | Purpose |
| --- | --- |
| `ml_engineer/scripts/` | Python exploration, classical models, gradient boosting, and neural-network experiments for longitudinal progression modelling. Shared helpers are in `scripts/_shared/`. |
| `ml_engineer/data/` | Inputs for the progression workflow, including the HDF5 feature matrix and CpG annotation. |
| `ml_engineer/results/` | Fold-level metrics, summaries, selected features, and figures from the model experiments. |
| `ml_engineer/reports/` | Analysis reports and report figures. |
| `bioinformatician/scripts/` | Download, QC/preprocessing, differential methylation, and plotting steps for GSE59685. |
| `bioinformatician/data/` | GEO data and array annotation/filter resources used by that workflow. Most inputs are large. |
| `bioinformatician/results/` | QC summaries, differential analysis tables, and plots. |
| `bioinformatician/reports/` | Analysis report and supporting files. |

## Workflow 1: longitudinal progression modelling

The modelling code uses an HDF5 matrix of 2,000 selected CpG features. It evaluates two binary transitions:

- **Control transition:** control versus control-to-MCI conversion.
- **MCI transition:** MCI versus MCI-to-AD conversion.

The scripts cover data inspection, baseline classifiers, XGBoost, linear and SVM models, deep-learning experiments, and report figure generation. Model validation and metrics are implemented in the scripts and shared helpers; consult those files and the generated result tables when interpreting a particular run.

### Environment

Use Python 3.10 or newer and install the listed packages in an isolated environment:

```bash
cd ml_engineer
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

PyTorch device support depends on the local machine. The experiment scripts accept a `--device` option; use `cpu` for a portable starting point, or select a supported accelerator such as `mps` where available.

### Run

From `ml_engineer/`, individual stages can be run from the scripts directory. For example:

```bash
cd scripts
python 01_describe_array.py
python 02_task1_baselines.py
```

The provided `commands.sh` records a broader sequence of experiments and figure generation. It includes multiple deep-learning runs and is computationally expensive; review it before running the full sequence. Outputs are written below `ml_engineer/results/` and `ml_engineer/reports/`.

## Workflow 2: GSE59685 whole-blood analysis

This workflow downloads the GEO inputs and array filtering resources, performs sample/probe QC and preprocessing, fits differential methylation models, and creates annotated tables and plots.

### Environment

The scripts require Python 3, R, and Bioconductor packages. One Conda/Mamba environment can be created with:

```bash
mamba create -n methylation-gse59685 \
  -c conda-forge -c bioconda \
  python=3.11 python-numpy python-pandas \
  r-base r-optparse r-data.table r-quadprog \
  bioconductor-limma bioconductor-minfi \
  bioconductor-flowsorted.blood.450k \
  bioconductor-summarizedexperiment
mamba activate methylation-gse59685
```

### Run

From `bioinformatician/`:

```bash
bash scripts/00_download_geo_data.sh
python3 scripts/01_preprocess_gse59685.py
Rscript scripts/02_differential_analysis.R
Rscript scripts/03_plot_results.R
```

The download step retrieves large public inputs into `bioinformatician/data/`. Outputs are written below `bioinformatician/results/`. Re-running the download script skips files that are already present and non-empty.

## Data and generated files

Input data and generated result tables are kept out of Git. The progression workflow expects `ml_engineer/data/temporal_two_sets_n2000.h5` and its CpG annotation file; obtain the HDF5 input through the appropriate data access route and place it at that path. The GEO workflow downloads its public inputs into `bioinformatician/data/` using its download script. Results can be regenerated by running the analysis scripts.

## Scope and interpretation

These are exploratory analyses of research datasets. Predictive performance and differential methylation findings depend on cohort definitions, preprocessing, validation design, and model choices. They should not be interpreted as clinical evidence or as a validated diagnostic tool.
